# Legacy Scripts

This directory contains experimental and legacy scripts from the development process.

## Files

- `xgboost-prediction.py` - Original XGBoost implementation
- `random_forest.py` - Random Forest experiments
- `webscrape_*.py` - Web scraping implementations
- `analyze.py` - Data analysis scripts
- Various model files and experimental code

These files are kept for reference but are not part of the production system.
